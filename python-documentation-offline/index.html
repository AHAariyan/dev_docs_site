What is in the Python docset

The Python docset mirrors the official documentation: the tutorial, the language reference, the standard library reference, the C API and the HOWTO guides. Every module, class, function, method and attribute is its own search entry, so a search for lru_cache lands on functools.lru_cache directly instead of on a long page you have to scroll.

Entries keep their dotted names. That makes Python one of the nicest docsets to search: type a module name and a dot (pathlib.) and you get the whole API of that module as a list.

How to get the Python documentation offline

  1. Install DevDocs from Google Play. It is free and needs no account.
  2. Open the Store tab and search for Python.
  3. Tap Download. The docset downloads in the background (28.8 MB compressed) and is indexed on your phone.
  4. Open Search or the docset in your Library. From now on it works with no connection.

Tips for searching the Python docs

  • Search the dotted path when a name is common: json.dumps is quicker to find than dumps.
  • Open a docset and use its type filter to list only Modules, which works like a table of contents for the standard library.
  • Bookmark the pages you keep returning to (string formatting, datetime format codes). Bookmarks open at the exact section.
  • The docset is updated when the upstream feed publishes a new version; the Store shows when an update is available.

Python docs offline: questions

Which Python version does the docset cover?

The catalogue's Python docset is version 3.15.0 at the time of writing (October 2026). When the feed publishes a newer build, DevDocs offers it as an update in the Store.

Is the standard library included?

Yes. The library reference is the bulk of the docset: 319 modules and more than 16,000 searchable entries in total.

Can I also get NumPy, Pandas or Django docs?

Yes. NumPy, Pandas, SciPy, Matplotlib, Flask, SQLAlchemy and Django are separate docsets in the same Store. Install the ones you use; search covers all of them at once.
