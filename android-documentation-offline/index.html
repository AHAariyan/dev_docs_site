What is in the Android (Kotlin) docset

The Android (Kotlin) docset is the developer reference for the Android framework and the AndroidX libraries (Lifecycle, Room, WorkManager, RecyclerView, Compose and the rest), with signatures shown in Kotlin. Classes are listed by their fully qualified names, so androidx.lifecycle.ViewModel and androidx.lifecycle.AndroidViewModel are easy to tell apart.

It is the largest docset most people install: about 299 MB compressed and over 200,000 entries. Downloads run in the background, survive closing the app and resume if the connection drops. Use the "Download over Wi-Fi only" setting if you are on mobile data.

How to get the Android (Kotlin) documentation offline

  1. Install DevDocs from Google Play. It is free and needs no account.
  2. Open the Store tab and search for Android (Kotlin).
  3. Tap Download. The docset downloads in the background (299 MB compressed) and is indexed on your phone.
  4. Open Search or the docset in your Library. From now on it works with no connection.

Tips for searching the Android (Kotlin) docs

  • Search the class name you remember (WorkManager), then pick the fully qualified result.
  • Methods and properties are separate entries, so viewModelScope finds the extension property directly.
  • Check free space first: DevDocs shows how much storage each docset uses and how much is left on the device.

Android (Kotlin) docs offline: questions

Is this the same as the Android developer reference online?

It is the API reference (classes, methods, constants) for the Android framework and AndroidX, in its Kotlin form. The long-form guides and codelabs on the website are not part of it.

How much space does it need?

About 299 MB to download, and more once unpacked. DevDocs shows the storage used per docset and warns when the device is running low.

Does it work in Android Studio?

No. DevDocs is an Android app that reads the docs on your phone or tablet. It is a companion for when you are away from your desk, or for a second screen next to it.
