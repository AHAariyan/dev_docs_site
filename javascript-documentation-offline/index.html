What is in the JavaScript docset

The JavaScript docset is generated from MDN Web Docs, the reference most web developers already use. Built-in objects (Array, Map, Promise, Intl…) are listed with their full prototype paths, statements and keywords have their own entries, and the guides are included too.

It is a big download, about 327 MB compressed, because the pages carry MDN's examples and related web material. Use Wi-Fi: DevDocs has a "Download over Wi-Fi only" setting, and downloads resume if the connection drops.

How to get the JavaScript documentation offline

  1. Install DevDocs from Google Play. It is free and needs no account.
  2. Open the Store tab and search for JavaScript.
  3. Tap Download. The docset downloads in the background (327 MB compressed) and is indexed on your phone.
  4. Open Search or the docset in your Library. From now on it works with no connection.

Tips for searching the JavaScript docs

  • Type the prototype path for instance methods, for example Array.prototype.at; static methods are just Object.groupBy style.
  • Keywords such as async function, let or class are entries of type Keyword.
  • Pair it with the TypeScript, NodeJS and HTML/CSS docsets so one search covers the whole front-end stack.

JavaScript docs offline: questions

Where does the JavaScript docset come from?

It is built from MDN Web Docs and published through the official docset feed. DevDocs downloads it and indexes it on your phone.

Why is the download so large?

About 327 MB compressed, because it includes MDN's pages with their examples and related web material. After that it costs no data at all.

Is Node.js included?

Node.js is a separate docset (NodeJS) in the Store, about 11 MB. Install both and search covers both.
