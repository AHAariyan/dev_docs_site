What is in the Kotlin docset

This docset is the API reference of the Kotlin standard library (kotlin.collections, kotlin.text, kotlin.sequences, scope functions such as let and apply, and the rest of stdlib). It comes from the community-contributed catalogue, where the current build is version 1.9.20.

Two honest limits: the docset is the standard library, not the language guide, and kotlinx.coroutines is not part of it. For Android APIs written in Kotlin, install the separate Android (Kotlin) docset.

How to get the Kotlin documentation offline

  1. Install DevDocs from Google Play. It is free and needs no account.
  2. Open the Store tab and search for Kotlin.
  3. Tap Download. The docset downloads in the background (91.1 MB compressed) and is indexed on your phone.
  4. Open Search or the docset in your Library. From now on it works with no connection.

Tips for searching the Kotlin docs

  • Many collection functions have several overloads (for List, Sequence, Map…). They show as separate results; the docset name under each result helps you pick.
  • Install Kotlin together with Android (Kotlin) and Java: one search then covers all three, which is handy when a Java API is called from Kotlin.
  • Use the reader's font size and reading-width settings for long signatures on a small screen.

Kotlin docs offline: questions

Is this the latest Kotlin version?

No. The community catalogue currently publishes Kotlin stdlib 1.9.20. Most of the standard library is unchanged since then, but newer additions will be missing until the catalogue is updated.

Are coroutines included?

No. The docset covers the standard library only; kotlinx.coroutines is not in it and there is no separate coroutines docset in the catalogue today.

How big is the download?

About 91 MB compressed. It takes more space once unpacked, and DevDocs shows the storage used per docset.
