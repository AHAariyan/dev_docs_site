What is in the Django docset

The Django docset is the official documentation: tutorials, topic guides, the model and QuerySet reference, class-based views, every setting and every manage.py command. Settings and commands have their own entry types, so a search for makemigrations or ALLOWED_HOSTS goes straight to the right section.

At about 10 MB it is quick to download, and it pairs naturally with the Python docset.

How to get the Django documentation offline

  1. Install DevDocs from Google Play. It is free and needs no account.
  2. Open the Store tab and search for Django.
  3. Tap Download. The docset downloads in the background (10.0 MB compressed) and is indexed on your phone.
  4. Open Search or the docset in your Library. From now on it works with no connection.

Tips for searching the Django docs

  • Method entries use full paths such as django.db.models.query.QuerySet.filter; typing just QuerySet.filter finds them.
  • Search a setting name in capitals (DATABASES) to jump to its reference.
  • Django REST framework is available as a community-contributed docset in the same Store.

Django docs offline: questions

Which Django version is it?

The official feed currently publishes Django 6.1.2. DevDocs offers updates when the feed publishes a newer version.

Is Django REST framework available too?

Yes, as a community-contributed docset in the DevDocs Store. Install both and search covers both.

Do I need the Python docset as well?

No, each docset stands alone. Many people install both so one search covers Django and the standard library.
